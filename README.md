# MangaRay

### Baca manga, manhwa, dan webtoon dengan tampilan ala Webtoon
Aplikasi Android untuk menemukan dan membaca komik, dengan antarmuka yang dibuat mirip Webtoon.

> **MangaRay adalah fork dari [Mihon](https://github.com/mihonapp/mihon), berlisensi Apache 2.0, dengan perubahan UI.**
> Proyek ini tidak berafiliasi dengan, dan tidak didukung oleh, proyek Mihon.

*Membutuhkan Android 8.0 atau lebih baru.*

## Fitur

<div align="left">

* Tampilan ala Webtoon: tab Home, Daily, Jelajahi, My, dan Lainnya.
* Pembaca dengan banyak mode baca dan pengaturan.
* Kategori untuk mengatur pustaka.
* Tema terang dan gelap.
* Jadwal pembaruan pustaka otomatis untuk chapter baru.
* Backup lokal atau ke layanan cloud pilihan lu.
